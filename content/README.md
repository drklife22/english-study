# 표현 원본 파일 형식

회차마다 `weekNN.txt` 하나를 만듭니다. 수정한 뒤에는 꼭 아래 명령으로 `data/`를 다시 만드세요.

```bash
python3 tools/build_data.py
```

오류가 있으면 줄 번호와 함께 알려 줍니다.

## 형식

```
week: 11
date: 2026-11-22
title: 영상 제목(한국어 가능)
subtitle: 부제목
video: https://youtu.be/...

## 표현 | 뜻 | 뉘앙스·쓰임 설명(선택)
match: 문단 체크에 쓸 형태1; 형태2      ← 선택. 불규칙 변화(blew, took…)가 있으면 적어 주기
- 영어 예문, 표현 부분은 [대괄호]로. = 한국어 해석
- 예문은 2~3개

@role 상황 설명 | 상대방 대사(영어) | 사용할 표현1; 표현2 | 모범 답안
@para 문단 주제 | 사용할 표현1; 표현2; 표현3 | 모범 문단
```

- `@role`, `@para`의 표현 이름은 같은 파일의 `## 표현` 이름과 똑같이 적습니다.
- 대괄호 `[ ]` 부분은 빈칸 문제의 정답과 하이라이트로 쓰여요.
- PDF의 대본이나 예문을 그대로 옮기지 말고 새로 쓴 예문을 넣습니다 (공개 저장소).
